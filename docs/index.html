    Install the app

    The desktop app detects your real hardware, including NVIDIA and AMD GPUs, so you do not have to type anything in. It installs for your user only, with no admin rights or sudo.

    Windows

    Download the app, or paste the one-line installer into PowerShell. It adds a Start Menu shortcut.

    Download can-i-run-ai.exe
    irm https://raw.githubusercontent.com/TonyXdZ/can-i-ai/main/install.ps1 | iex

    The app is not code-signed, so SmartScreen may warn you once. Choose More info, then Run anyway.

    Linux

    Download the binary, or run the one-line installer in a terminal. It adds an entry to your app menu.

    Download can-i-run-ai-linux
    curl -fsSL https://raw.githubusercontent.com/TonyXdZ/can-i-ai/main/install.sh | bash

    Prefer Python? Run pip install -r requirements.txt and then python can_i_run_ai.py from the source.

    How the check works

    For each model, the app estimates the memory it needs at four quantization levels, then compares that to your GPU memory and the RAM left after your system takes its share.

    memory needed = parameters x bytes per parameter + 1.5 GB
    QuantizationBytes per parameterExample: 7B model
    Q4_K_M0.60 GB5.7 GB
    Q5_K_M0.70 GB6.4 GB
    Q8_01.07 GB9.0 GB
    FP162.00 GB15.5 GB

    The extra 1.5 GB covers context and runtime. The app keeps 3 GB of RAM free for your operating system and uses 95% of your GPU memory.

    What the results mean

    Fast on GPUFits fully in GPU memory.
    GPU + RAMSplit between GPU and RAM. Slower.
    CPU onlyRuns from system RAM. Slow.
    Too bigDoes not fit, even at Q4.

    Frequently asked questions

    How much VRAM do I need to run a 7B model?

    With 4-bit quantization (Q4_K_M), a 7B model needs about 5.7 GB of memory by the estimate this app uses: parameters x 0.6 GB per billion, plus 1.5 GB for context and runtime. That fits on an 8 GB GPU. At Q8_0 the same model needs about 9 GB.

    Can I run local AI models without a GPU?

    Yes. Models can run from system RAM on the CPU, but more slowly. The app keeps 3 GB of RAM free for your operating system, so a 16 GB computer has about 13 GB to give a model.

    Is Can I Run AI? free and open source?

    Yes. It is free and released under the MIT license. The source code is on GitHub.

    Does it work offline?

    The desktop app does. It uses a cached or bundled model list when there is no internet connection. The checker on this page runs entirely in your browser and sends nothing anywhere.

    Is the app safe to install?

    The apps are not code-signed, so Windows SmartScreen may warn you the first time: choose More info, then Run anyway. The installers work for the current user only (no admin rights or sudo), and the scripts are short enough to read before you run them.

    How accurate are the results?

    They are estimates. Real memory use changes with context length and with the program you use to run the model. On Windows, VRAM on non-NVIDIA GPUs can be misreported because of a limit in the Windows API.

    Which GPUs does it detect?

    NVIDIA and AMD GPUs, with VRAM, on Windows and Linux. For NVIDIA cards the driver must be installed so that nvidia-smi works.
